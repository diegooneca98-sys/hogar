# Hogar

App de casa de Diego y Leire: dashboard del día, lista de la compra, tareas, gastos y recibos.

- Web estática (PWA) publicada con GitHub Pages: https://diegooneca98-sys.github.io/hogar/
- Datos en Supabase (proyecto «apps-diego»), con acceso solo para los miembros de casa.
- La clave de `config.js` es la clave pública (publishable) de Supabase; la seguridad la dan las políticas RLS.
